# Chrome Web Store 제출 자료

이 문서는 현재 확장 코드와 개인정보 공개가 일치하는지 검토하기 위한 제출
원본입니다. 실제 Web Store 양식에는 아래 내용을 축약하거나 의미를 넓히지 않고
옮깁니다.

## 기본 정보

- 이름: `coupangctl 일반 브라우저 연결`
- 짧은 설명: `선택한 쿠팡 주문목록 탭을 내 컴퓨터의 coupangctl에 한 번 연결합니다.`
- 카테고리: 생산성 도구
- 언어: 한국어

상세 설명:

> 내 쿠팡 주문 기록을 내 컴퓨터에서 분석하는 로컬 우선 오픈소스
> `coupangctl`의 브라우저 연결 확장입니다. 먼저 터미널이나 AI 클라이언트에서
> 일반 브라우저 동기화를 시작한 뒤, 로그인된 쿠팡 주문목록 탭에서 팝업을 열고
> **이 탭 연결**을 누릅니다. 선택한 탭의 주문일·금액·상품·배송 상태만 정규화해
> 같은 컴퓨터의 `coupangctl`로 보냅니다. 쿠키와 로그인 정보는 읽지 않고,
> 확장에 결과를 저장하지 않으며, 개발자나 외부 서버로 보내지 않습니다.
> 자동 주문과 결제는 지원하지 않습니다. 쿠팡의 공식 제품이 아닙니다.

## 단일 목적

사용자가 명시적으로 승인한 현재 쿠팡 주문목록 탭의 정규화된 주문 기록을 로컬
`coupangctl` 프로세스로 한 번 전달합니다.

## 권한 설명

| 권한 | 제출용 설명 |
| --- | --- |
| `activeTab` | 팝업에서 사용자가 **이 탭 연결**을 누른 현재 탭에만 임시로 접근하기 위해 필요합니다. |
| `scripting` | 패키지에 포함된 reader를 승인된 탭의 top frame에서 한 번 실행해 허용된 주문 필드만 정규화하기 위해 필요합니다. |
| `nativeMessaging` | 정규화된 결과를 같은 컴퓨터에 설치된 `coupangctl` 프로세스로 전달하기 위해 필요합니다. |

host permission, 쿠키, 저장소, 외부 메시지, incognito 권한은 요청하지 않습니다.
원격 코드를 실행하지 않으며 모든 JavaScript와 CSS는 제출 ZIP 안에 포함됩니다.

## 개인정보 공개 답안

확장이 처리하는 범주:

- 웹사이트 콘텐츠: 사용자가 선택한 주문목록 탭의 주문·상품·배송 필드
- 사용자 활동: 사용자의 구매 기록
- 금융 정보: 주문 금액, 할인액, 배송비, 표시 단가·결제액

각 범주의 유일한 사용 목적은 앱 기능 제공입니다. 데이터는 판매하지 않고,
광고·신용 평가·대출·보험·제3자 프로파일링에 사용하지 않습니다. 개발자 서버나
제3자에게 전송하지 않습니다. 정규화된 결과는 사용자 컴퓨터의 Native Messaging
호스트로 전달되고 확장에는 저장되지 않습니다.

공개 개인정보 처리방침 URL:
`https://github.com/JungHoonGhae/coupang-ctl/blob/main/PRIVACY.md`

## 제출 전 증거 체크리스트

- [ ] `npm run test:extension`이 통과한다.
- [x] 16·48·128 RGBA 아이콘이 manifest와 내장 번들에 포함되고 크기 계약 테스트를 통과한다.
- [x] `cmd/extensionpack`이 열 개의 허용 파일만 ZIP 루트에 결정론적으로 기록하고 SHA-256을 반환한다.
- [ ] 제출 직전 새 경로에서 ZIP을 만들고 `--verify`로 파일 허용 목록과 SHA-256 검사를 다시 통과한다.
- [ ] 새 Chrome 프로필에서 팝업 고지 → 명시적 연결 → 로컬 동기화를 확인한다.
- [ ] 잘못된 탭, 실행 중인 CLI 없음, 네이티브 호스트 없음 상태를 확인한다.
- [ ] Web Store 대시보드의 데이터 사용 답안이 이 문서 및 `PRIVACY.md`와 같다.
- [ ] 스토어 아이콘과 스크린샷이 실제 UI이며 쿠팡 상표나 실제 주문 데이터를
      오해하게 사용하지 않는다.
- [ ] 최소 한 장의 실제 UI 스크린샷과 small promo tile을 규격에 맞춰 등록한다.
- [ ] 첫 비공개 대시보드 업로드 뒤 Web Store public key와 할당된 extension ID가
      native-host allowlist의 ID와 같은지 확인하고, 다르면 manifest key·Go 상수·
      계약 테스트를 한 변경으로 맞춘다.
- [ ] Chrome Web Store 검토 승인을 받기 전 자동 설치나 승인 상태를 주장하지
      않는다.

기술 패키지는 다음 명령으로 생성·재검증합니다. ZIP 업로드, 공개 key 확인,
개인정보 답안 입력, 심사 요청은 별도의 외부 작업입니다.

```bash
go run ./cmd/extensionpack --output /new/path/coupangctl-extension.zip
go run ./cmd/extensionpack --verify /new/path/coupangctl-extension.zip
```
